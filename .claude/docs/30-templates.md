# 30 - 派工 prompt 模板

用法：複製對應模板 → 填 `【】` 空格 → 用 Agent 工具派給表頭指定的 agent。
`subagent_type` 填 agent 名稱（scout / worker / verifier / reviewer），model 與 effort 已在 agent 定義檔寫死。
三件套（目標與動機、驗收條件、回報格式）是骨架，刪掉任何一段都算不合格派工。

---

## 模板 1：搜尋 / 定位（派給 scout）

```
目標：找出【要找的東西，例如：所有讀寫 gold 數值的位置】。
動機：【為什麼要找，例如：接下來要把 gold 改成 long，需要知道影響範圍】。
範圍：【檔案/目錄，例如：*.c *.h，排除 prompt.txt】。

驗收條件：
- 每個結果附 檔案:行號 與一行說明。
- 對搜過但沒有結果的 pattern 也要列出（證明你搜過）。
- 每個結論標注〔確認〕或〔推測〕。

回報格式：條列，總長 ≤ 30 行。不貼超過 5 行的程式碼。
```

## 模板 2：實作（派給 worker）

```
目標：【要做的改動，例如：在 magic.c 新增第四種魔法卡「Double Score」，價格 100】。
動機：【為什麼，例如：使用者要求增加策略深度；價格由使用者指定不可改】。
相關位置：【已知的檔案:行號，例如：magic.c 的商店選單在 OfferMagicChoice()】。不知道位置就二選一：先用模板 1 派 scout 查完再派工；或在此填「位置未知，請自行 Grep 定位」讓 worker 自己找。
不要動：【明確排除範圍，例如：不要改既有三種卡的價格與效果】。

驗收條件：
- [ ] gcc 編譯零 error（指令見 CLAUDE.md）。
- [ ] CLI 版冒煙測試：買得到新卡、效果生效、gold 正確扣款。
- [ ] 【任務專屬條件，例如：gold 不足時不可購買且不扣款】
- [ ] git diff 無調試殘留、無二進位檔。

回報格式：改動檔案清單（檔案:行號）＋驗收條件逐條勾選＋未驗證項明列。≤ 30 行。
不要 commit，由主對話統一 commit。
```

## 模板 3：重構（派給 worker）

```
目標：【重構內容，例如：把 ui_raylib.c 裡重複三次的按鈕繪製邏輯抽成函式】。
動機：【例如：後續要加新按鈕，重複碼會讓每次修改要改三處】。
硬性約束：**外部行為零改變**。這是重構，任何行為差異都算失敗。

驗收條件：
- [ ] 編譯零 error、零新增 warning。
- [ ] 重構前後對照：【可觀察行為的驗證法，例如：CLI 版同一種子跑同一輪操作，輸出逐字相同】。
- [ ] 重複碼確實消除（指出新函式位置與三個呼叫點）。

回報格式：同模板 2。若發現重構會不可避免地改變行為，停手回報，不要硬做。
```

## 模板 4：研究（派給 scout；需要深度判斷時派 reviewer）

```
目標：回答以下問題：【具體問題清單，一次最多 5 題】。
動機：【這些答案將決定什麼，例如：決定要不要把存檔功能做成 JSON】。
資訊來源優先序：【例如：官方文件 > 本 repo 現況 > 一般網頁】。

驗收條件：
- 每題有明確答案或明確的「查不到」。
- 每個答案附來源（URL 或 檔案:行號）。
- 區分「文件明說的」與「你推論的」。

回報格式：每題一段（答案 1-2 句 + 來源）。≤ 30 行；超長的整理寫進
【/tmp/research-主題.md】只回傳路徑。
```

## 模板 5：審查 / 驗收

驗收（派給 verifier——注意：**只給驗收條件與路徑，不要描述做事過程**，避免帶風向）：

```
請驗收以下產出，逐條標注 PASS / FAIL / 無法驗證（附原因）：
- 檔案：【路徑清單】
- 驗收條件：【原派工單的條件，逐條列出】
- 程式碼類請實際編譯與執行（指令見 CLAUDE.md），附關鍵輸出行。
回報格式：逐條勾選結果 + 發現的問題清單（檔案:行號）。你只找問題，不修。
```

審查 / 第二意見（派給 reviewer）：

```
背景：【問題與目前提案，或完整失敗軌跡：每次試了什麼、錯誤訊息原文】。
請獨立判斷：
1. 提案/方向哪裡對、哪裡錯或有風險？
2. 你會怎麼做？若判斷方向本身錯了，直說「換路」並給新方向。
回報格式：≤ 40 行，每個判斷附依據。品味類判斷要明標「這是品味判斷」。
```

---

## 通用附註（每個派工都適用，不用重複貼進 prompt——已寫在 agent 定義檔裡）

- subagent 會自己讀 CLAUDE.md 的禁令。
- 失敗回報必附：試了什麼、錯誤訊息原文末 10 行。
- 長產物落檔傳路徑，不進主對話。
